# 海外调研日程

网址：https://yufei-wang.github.io/overseas-tour/

网站分三块：正在报名、即将进行（列表 / 月历）、往期调研。点任何一个活动，可以看到完整的要素卡。

## 怎么更新

- **在对话里改**：把券商的段子或 PDF 发给 Claude（「overseas tour」项目）。Claude 会整理成要素卡，你确认后写进这里，大约 1 分钟后网站更新。
- **在后台改**：在网址后面加 `#admin`，或者点网页底部的「管理」，用 GitHub 访问密钥登录。在后台可以开关报名、改活动、标星、填写部门报名名单、导出 Excel。

## 文件说明

- `index.html`：网页本身
- `data/events.json`：所有活动的公开信息
- `files/<活动编号>/`：活动附件（PDF、海报等）

部门报名名单、内部备注、段子原文都不在这个仓库里，存放在不公开的仓库 `overseas-tour-data`。
